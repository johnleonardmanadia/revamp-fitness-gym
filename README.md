# REVAMP Fitness

Landing page built with HTML5, CSS3 and Vanilla JavaScript only.

## Structure
```
index.html
css/style.css
js/script.js
assets/images/   hero, why-center, coach-*, avatar-*, program-*
assets/icons/
```

## Features
- Mobile nav toggle, smooth scrolling
- Scroll animations, looping highlights carousel, count-up stats
- FAQ accordion, program slider, testimonial slider
- Pricing buttons select a plan; the CTA opens a booking dialog (no data is sent anywhere)

## Run
Open `index.html` in a browser, or deploy the folder to Vercel/Netlify.
